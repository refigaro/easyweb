The brief: "make it look like it was built by grids"

Architecture firms think spatially. When the founder of P+H came to us with their website redesign, they didn't describe what they wanted in words — they built a wireframe in Excel. Rows and columns. Cells precisely sized to represent image blocks, text areas, and whitespace. It was rough, but it was exact.

The brief was clear: the site should feel like it was constructed. Grid-based layout, clean geometry, architectural precision. The kind of visual language that says "we think in structure" — because they do.

The challenge wasn't interpreting the vision — it was preserving it across screen sizes. A rigid grid that looks architectural on a 1440px desktop becomes a usability problem on a 390px mobile screen. That tension between aesthetic intent and responsive behavior was the core technical problem of this project.

Started from an Excel wireframe

The founder sketched the entire site layout in a spreadsheet — cell widths, proportions, content placement. This is more common than people think. Clients who aren't designers still have clear ideas about what they want. The job is translating that accurately, not dismissing it in favor of your own aesthetic preferences.

How we built it

1

Translating the grid from Excel to Figma

The first step was mapping the Excel wireframe to actual web proportions. We rebuilt the layout in Figma — respecting the spatial relationships the client had defined, but adjusting proportions for real screen dimensions and adding the visual refinements an architecture firm's brand requires: typography hierarchy, whitespace, image treatments.

The design uses a system of stacked rectangular containers — some full-width image blocks, some split grid sections, some text areas. Each block is visually discrete, like architectural panels. The horizontal rhythm is consistent across all pages.

2

WordPress + Elementor Pro: building the container system

Development used WordPress with Elementor Pro as the page builder — a deliberate choice for a client that needed to manage their own portfolio content. Adding a new project, swapping gallery images, or updating project descriptions needed to be tasks the firm could handle independently after launch.

Each page section is a modular container: the project galleries, the services list, the contact block. The structure is reusable across pages — Oficinas, Locales Comerciales, and Casas each follow the same grid template but with their own content. This keeps the visual system consistent and makes content management straightforward.

3

The mobile challenge: preserving the grid without breaking it

This was the hardest part. A grid-based layout with side-by-side image blocks and text panels looks intentional on desktop. On mobile, if you simply collapse everything to a single column, the architectural rhythm disappears and you're left with a generic-looking stack of content.

The solution was to design the mobile breakpoints as a deliberate vertical composition — not a fallback. Each block stacks in a defined order that preserves the visual hierarchy: image first, then text. The proportions shift from landscape-heavy to portrait-friendly. The grid logic holds; it just becomes vertical instead of horizontal. The result reads as intentional on a phone, not as a collapsed desktop layout.

Site structure

Five pages, each serving a distinct purpose in the client's business funnel.

1

Homepage

Main entry point. Leads with the value proposition and the three service categories. Direct access to the contact form above the fold — reducing the steps between "interested visitor" and "submitted lead."

2

Nosotros (About)

20+ years of experience framed as credibility. The page addresses the implicit question any high-ticket service buyer has: "Why should I trust these people with my project?"

3

Oficinas

Portfolio of corporate office projects. Image-heavy grid layout. Each project is a visual proof of capability for commercial clients considering a workspace redesign or build-out.

4

Locales Comerciales

Commercial retail and restaurant projects. Same grid structure as Oficinas but scoped to a different buyer segment — restaurateurs, retailers, and business owners redesigning their customer-facing spaces.

5

Casas

Residential projects — houses and apartments. The visual language shifts slightly to feel warmer and more personal, while maintaining the architectural grid that defines the brand across the entire site.

The navigation structure matters. Separating projects by type — not just a generic "Portfolio" page — means each visitor sees work relevant to their project from the first click. A restaurant owner lands on Locales Comerciales and sees exactly their use case. No filtering required.

What this project shows

Working with the client's vision, not against it

The client came with an Excel wireframe. A less attentive designer would dismiss it and start from scratch. We translated it exactly — because the client knew what they wanted. Our job is to make it work technically, not to redesign someone's brand from the ground up uninvited.

Solving design constraints, not ignoring them

The grid-on-mobile problem had no obvious solution. We designed around it — treating mobile as a vertical composition in its own right, not a collapsed version of desktop. That's the difference between responsive design and truly adaptive design.

Building for the client's long-term independence

The site is self-managed through WordPress. Adding new projects, updating the gallery, editing copy — all done by the firm without calling us. This is the standard on every Easyweb project: you own the site and you can run it.

Modular design that scales

Three service pages (Oficinas, Locales, Casas) use the same underlying grid template. Adding a fourth category in the future — say, industrial projects — is a matter of duplicating the structure and filling in new content. No redesign required.
